# Arduino-Projects-1
This is my very first Arduino project uploaded to Github. It is a simple program that runs on the microcontroller.

## Hardware Components Used
*Arduino Uno Board
*Connecting Wires[12]
*Breadboard [1]
*560 ohm resistors [4]
*LED [Red-1, Blue-1, Green-1, Yellow-1]
*Potentiometer [1]

## How to use this code
1.Open the '.ino' file in the Arduino IDE.
2.Connect your Arduino Board to the computer.
3.Select the correct board.
4.Click 'Upload'
